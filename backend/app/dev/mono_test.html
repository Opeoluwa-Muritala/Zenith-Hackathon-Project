Ready. Start with “Request OTP”.
Local webhook requirement
  1. Set AGGREGATOR_PROVIDER=mono and WEBHOOK_SECURE_KEY in backend/app/.env.
  2. Expose local port 8000 through an HTTPS tunnel you control.
  3. Point the Mono sandbox webhook to https://<tunnel>/webhooks/mono with the matching secret.
  4. Use the configured redirect URL. The page polls status, but only a delivered webhook activates a hosted link.
Do not use a production key or real customer information in this panel.
